# Tinjauan lokalisasi bahasa Indonesia

Seluruh 72 label ekspor kartu gaya kini memiliki teks bahasa Indonesia, mencakup identitas, batas wajib, sumber, gaya, persyaratan jawaban, pemeriksaan mutu, dan instruksi sistem. Beberapa istilah dan kalimat yang terasa kaku juga diperhalus.

Pemeriksaan sintaks JavaScript dan diff akan dijalankan setelah rangkaian lokalisasi selesai. Pengujian interaksi menyeluruh di browser belum dilakukan.
