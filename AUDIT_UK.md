# Перевірка української локалізації

Додано повний набір українських текстів для 72 полів експорту стильової картки: ідентичність, обов’язкові обмеження, джерела, стиль, вимоги до відповіді, контроль якості та системна інструкція. Відредаговано окремі буквальні формулювання.

Перевірки синтаксису JavaScript і формату diff буде виконано після завершення серії локалізацій. Повне інтерактивне тестування в браузері не проводилося.
