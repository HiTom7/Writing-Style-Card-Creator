# Проверка русской локализации

Проверены ключевые подписи экспорта. Добавлен полный комплект русских строк для всех 72 полей экспортируемой карточки: от идентичности и ограничений до источников, качества и системной инструкции. Формулировки приведены к естественному русскому интерфейсному стилю.

Проверка синтаксиса JavaScript и `git diff --check` выполняется после серии локализаций; полноценное браузерное тестирование не проводилось.
