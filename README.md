# Writing Style Card Creator

Multilingual step-by-step writing style profiler for LLMs.

## Languages
English, Spanish, Polish, German, French, Italian

## Usage
Open `index.html` in a browser. No build step required.

1. Switch language with flags at the top
2. Go through steps, multi-select options or write your own
3. Download `.md` file ready as system prompt for any LLM

## Features
- 9 style dimensions + examples
- ~20 culturally adapted options per section per language
- Export Markdown styleguide
